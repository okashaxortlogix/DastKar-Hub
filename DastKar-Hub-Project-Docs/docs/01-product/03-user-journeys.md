# Core User Journeys

## Buyer journey

Landing → category/search → product → maker → variant/customization → cart → address → shipping → payment → order confirmation → tracking → delivery → review → repeat discovery.

## Maker journey

Invite/social link → registration → verification → storefront → product creation → publish → share link → order → accept/prepare → handoff → delivered → payout → review → analytics.

## Customized order

Product → choose customization → seller-defined lead time → checkout → seller receives structured customization → seller accepts → production → shipment → delivery → review.

## Dispute journey

Customer reports issue → evidence requested → seller response → operations review → decision → refund/replacement/denial → case closed → audit log.

## Verification journey

Seller signup → documents/evidence → automated validation where possible → operations review → approved/rejected/changes requested → seller notified.
