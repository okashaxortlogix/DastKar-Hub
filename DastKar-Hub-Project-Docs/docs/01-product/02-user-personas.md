# User Personas

## Persona 1 — Home-based Maker

Needs:
- easy onboarding
- simple product listing
- phone-first management
- trust badge
- order notifications
- reliable payout
- simple shipping workflow

Pain:
- social media DMs
- manual order tracking
- content creation
- customers asking repeated questions
- difficulty appearing trustworthy to new buyers

## Persona 2 — Established Craft Brand

Needs:
- branded storefront
- analytics
- catalog control
- promotions
- multiple variants
- staff access later

Pain:
- fragmented channels
- manual reporting
- marketplace competition

## Persona 3 — Discovery-driven Buyer

Needs:
- inspiration
- visual browsing
- maker stories
- reviews
- customization
- easy checkout

## Persona 4 — Gift Buyer

Needs:
- trustworthy quality
- customization
- delivery date
- gift packaging
- seasonal collections

## Persona 5 — Admin/Operations

Needs:
- verification queues
- fraud visibility
- order search
- dispute tools
- auditability
