# UX Design Direction

## Visual goal

A premium but practical marketplace.

Think:
- strong product photography
- clear typography
- compact cards
- structured filters
- visible price
- obvious CTA
- meaningful trust indicators
- subtle craft-inspired details

Do not make it look like:
- an AI startup landing page
- a crypto dashboard
- a glassmorphism SaaS app
- a futuristic neon interface

## Layout

### Desktop
- max content width: ~1280–1440px
- persistent header
- optional left filter rail on category pages
- product grid 4–5 columns depending on width
- seller dashboard uses denser tables/cards

### Tablet
- 3–4 product columns
- collapsible filters

### Mobile
- 2 product columns
- bottom-sheet filters
- sticky checkout CTA
- compact header
- thumb-friendly controls

## Homepage hierarchy

1. Header/search
2. Primary category navigation
3. Hero/seasonal campaign
4. Featured makers
5. Trending products
6. Category collections
7. Maker stories
8. Trust section
9. Footer

## Product page hierarchy

Gallery → title → rating → price → variants → customization → production time → shipping → trust → add to cart/buy → maker → details → reviews → related products.

## Seller dashboard hierarchy

Orders first, then revenue, inventory alerts, product management, store health, analytics.

## Motion

Use motion sparingly:
- hover
- drawer
- modal
- toast
- skeleton loading
- cart feedback

Avoid decorative animation.
