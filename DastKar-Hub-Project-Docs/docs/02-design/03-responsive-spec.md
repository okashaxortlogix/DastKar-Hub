# Responsive Specification

## Breakpoints

Use CSS breakpoints approximately around:
- 320–479: small mobile
- 480–767: mobile
- 768–1023: tablet
- 1024–1279: laptop
- 1280+: desktop

Do not design around device names alone. Components should adapt fluidly.

## Product grid

- mobile: 2 columns
- tablet: 3 columns
- desktop: 4–5 columns

## Touch targets

Minimum practical target: ~44px.

## Mobile seller experience

Prioritize:
1. Orders
2. Messages/notifications
3. Inventory
4. Add product
5. Store

## Performance

- responsive images
- AVIF/WebP where supported
- lazy loading below fold
- avoid huge JS bundles
- route-level code splitting
