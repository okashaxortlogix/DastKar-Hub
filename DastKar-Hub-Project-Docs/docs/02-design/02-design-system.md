# DastKar Design System

## Brand character

- craft-focused
- trustworthy
- contemporary
- Pakistani
- practical
- premium without being luxury-exclusive

## Typography

Recommended:
- Inter for interface/body
- Noto Sans Arabic or Noto Nastaliq Urdu where Urdu content requires it

Use 4–6 type scales, not dozens.

## Color strategy

Use a restrained neutral foundation:
- warm off-white/page background
- charcoal primary text
- neutral borders
- one brand accent
- semantic success/warning/error colors

Do not use gradients as the primary visual language.

## Buttons

Primary = main conversion action.
Secondary = alternative action.
Tertiary = low-emphasis action.
Destructive = irreversible/high-risk action.

## Cards

Avoid excessive nested cards. Use grouping and whitespace instead.

## Product imagery

Product image is the visual priority. Use consistent aspect ratios and lazy loading.

## Accessibility

Target WCAG 2.2 AA where practical:
- keyboard navigation
- visible focus
- sufficient contrast
- labels for inputs
- meaningful alt text
- reduced motion support
- accessible error states
