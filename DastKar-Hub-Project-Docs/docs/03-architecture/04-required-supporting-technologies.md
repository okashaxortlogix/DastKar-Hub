# Additional Technologies

## Required/strongly recommended

### Frontend
- React
- TypeScript
- Vite or Next.js
- TanStack Query
- React Hook Form
- Zod
- Tailwind CSS or CSS Modules

### Backend
- PHP 8.3+ compatible with selected Laravel release
- Laravel
- Composer
- Laravel queues
- Redis

### Database
- PostgreSQL 16+ recommended
- MySQL 8+ alternative

### Infrastructure
- Docker
- Nginx or managed ingress
- CDN
- S3-compatible storage
- Linux
- CI/CD

### Monitoring
- error tracking
- metrics
- centralized logs

## Optional later

- OpenSearch
- Elasticsearch
- Meilisearch
- dedicated analytics warehouse
- feature flag service
- vector database only if visual/recommendation search requires it

## Do not add initially

- Kubernetes
- microservices
- Kafka
- service mesh
- vector DB
- GraphQL
- multiple databases

Add them only when an actual requirement exists.
