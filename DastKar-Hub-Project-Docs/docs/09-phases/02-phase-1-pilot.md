# Phase 1 — Pilot

## Objective

Process real orders with minimum software.

## Scope

- 10–50 makers
- one focused category
- web marketplace
- manual operations allowed
- basic payment/logistics

## Measure

- visitors
- product views
- add-to-cart
- checkout
- completed order
- seller fulfillment
- refund
- repeat purchase

## Do not optimize

Do not spend the pilot building:
- social feed
- complex AI
- mobile apps
- advanced ML

## Exit

Move to full MVP when real users repeatedly complete the core loop.
