# Phase 0 — Discovery

## Objectives

1. Select launch category.
2. Recruit pilot makers.
3. Validate buyer problem.
4. Validate willingness to transact.
5. Establish baseline economics.

## Tasks

- interview 20–30 makers
- interview 20–30 buyers
- manually inspect social seller landscape
- document competitor workflows
- test marketplace landing page
- recruit 10–20 pilot makers

## Deliverables

- research notes
- category decision
- seller onboarding script
- buyer interview guide
- pricing hypothesis
- risk register

## Exit criteria

Proceed only if there is evidence of:
- seller willingness
- buyer interest
- product availability
- manageable fulfillment
