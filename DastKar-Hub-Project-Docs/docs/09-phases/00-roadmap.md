# Master Phase Roadmap

## Phase 0 — Discovery & Validation
Goal: prove demand before heavy development.

Deliver:
- interviews
- category selection
- seller interviews
- buyer interviews
- competitor analysis
- pricing/commission hypotheses

Exit:
- 20+ maker conversations
- 20+ buyer conversations
- clear first category
- pilot makers identified

## Phase 1 — Concierge Pilot
Goal: prove real transactions.

Build:
- lightweight storefronts
- manual seller onboarding
- basic catalog
- checkout
- manual operations if necessary

Exit:
- real orders
- fulfillment evidence
- initial buyer feedback

## Phase 2 — MVP Engineering
Build:
- React storefront
- Laravel API
- PostgreSQL
- seller dashboard
- admin dashboard
- payment integration
- courier integration
- reviews
- disputes

Exit:
- stable end-to-end transactions

## Phase 3 — Marketplace Validation
Build:
- improved search
- analytics
- referrals
- maker stories
- seller performance
- basic promotions

Exit:
- repeat buyers
- retained sellers
- measurable economics

## Phase 4 — AI & Scale
Build:
- AI listing assistant
- AI reels
- visual search
- recommendation improvements
- WhatsApp integrations

Exit:
- AI demonstrably improves seller productivity or buyer conversion

## Phase 5 — Expansion
Potential:
- new categories
- B2B
- diaspora
- international shipping
- native apps
