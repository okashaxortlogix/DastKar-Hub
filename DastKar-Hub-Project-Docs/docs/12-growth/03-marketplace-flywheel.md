# Marketplace Flywheel

Maker acquisition
→ more quality products
→ better discovery
→ more buyers
→ more orders
→ maker revenue
→ seller retention
→ maker referrals
→ more makers

## Important

The flywheel only works if:
- sellers are genuine
- products are good
- buyers trust the marketplace
- orders are fulfilled
- sellers earn enough to stay

Traffic without successful transactions does not create a healthy marketplace.
