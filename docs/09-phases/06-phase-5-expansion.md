# Phase 5 — Expansion

## Categories

Expand only after first category has:
- stable supply
- buyer demand
- repeat transactions
- manageable operations

## B2B

Potential:
- corporate gifting
- hotels
- restaurants
- interior designers
- event planners
- retailers

## International

Start with diaspora demand after domestic operations are stable.

Required:
- cross-border payments
- customs
- export documentation
- duties/taxes
- international courier
- returns
- seller export readiness
