# Domain Glossary

| Term | Meaning |
|---|---|
| Maker | A person/business that meaningfully creates, customizes, assembles or finishes products |
| Seller | A marketplace account approved to sell |
| Buyer | Customer purchasing products |
| Storefront | Public maker profile and product catalog |
| Product | Sellable catalog item |
| Variant | A product option such as size/color |
| Custom Order | Order containing buyer-specific customization |
| Verification | Process establishing seller identity and maker status |
| GMV | Gross merchandise value |
| AOV | Average order value |
| CAC | Customer acquisition cost |
| LTV | Customer lifetime value |
| RTO | Return to origin |
| COD | Cash on delivery |
| P2M | Person-to-merchant payment |
| Dispute | Formal customer/seller issue requiring platform resolution |
| Payout | Amount settled to seller |
| Moderation | Review/removal/restriction of user or product content |
