# Customer Support

## Tier 1

Automated/self-service:
- order status
- delivery tracking
- common policy questions
- account help

## Tier 2

Human:
- missing order
- damaged item
- wrong item
- seller issue
- refund

## Tier 3

Operations/risk:
- fraud
- serious disputes
- safety
- repeated abuse
- high-value cases

## SLA

Define SLAs after pilot data. Do not invent aggressive promises before operational capacity exists.
