# Privacy Blueprint

## Data minimization

Collect only what is necessary.

## Sensitive seller documents

- private object storage
- restricted access
- access logging
- retention policy
- deletion policy where legally possible

## Customer address

Use only for:
- fulfillment
- shipping
- customer support
- required records

Do not expose full address to unrelated sellers/users.

## Analytics

Prefer aggregated/anonymized analytics where possible.

## User controls

Plan for:
- account access
- profile updates
- appropriate deletion requests
- notification preferences
- privacy policy transparency

## Legal review

Before launch, have Pakistan-qualified counsel review privacy, consumer protection, e-commerce, tax, payments and data-retention requirements.
