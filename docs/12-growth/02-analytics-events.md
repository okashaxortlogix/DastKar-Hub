# Analytics Event Taxonomy

## Buyer events

- page_view
- search
- filter_applied
- product_view
- maker_view
- add_to_cart
- remove_from_cart
- checkout_started
- payment_started
- payment_completed
- order_completed
- review_submitted
- wishlist_added

## Seller events

- seller_registered
- verification_started
- verification_submitted
- verification_approved
- product_created
- product_published
- order_received
- order_accepted
- order_shipped
- payout_received
- ai_listing_generated
- ai_listing_approved

## Rule

Events should be stable, documented and versioned. Avoid collecting unnecessary personal data in event properties.
